NBA Game Database Project

In this semester project, we will work on a dataset containing statistical information of NBA games. Students are expected to perform relational database modeling, SQL querying, and basic data analysis.

Explore the Dataset

About the Dataset

  • Total number of games: 25,000+
  • Main fields: Team, player, date, score, assists, rebounds
  • Source: Kaggle NBA Games Dataset / Stats API

Course Objectives

Students will analyze the dataset and design properly structured relational tables. Example tasks include:

  • Top 10 highest-scoring games
  • Average score comparison between teams
  • Player performance trends across seasons
