About the Project

Project Description

This NBA Database Project is designed to manage and analyze comprehensive basketball game statistics. The system stores information about teams, players, games, performance metrics, and arena details in a structured relational database.

Database Structure

The database consists of five main tables: Teams (managing NBA team information), Players (storing player profiles and statistics), Games (recording match details), Player Statistics (tracking individual game performance), and Arenas (maintaining venue information). Each table is normalized and connected through foreign key relationships.
